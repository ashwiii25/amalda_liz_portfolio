# Amalda Liz - Portfolio Documentation

## Overview
This is a modern, responsive, and visually striking personal portfolio website for Amalda Liz. It is designed to showcase her work in modeling and film, featuring high-quality image galleries, cinematic transitions, and a clean, sophisticated aesthetic.

## Tech Stack & Framework
- **Framework:** React 18+
- **Build Tool:** Vite
- **Language:** TypeScript for type-safe code
- **Styling:** Tailwind CSS for utility-first styling and responsive design
- **Animations:** Motion (Framer Motion) for smooth, cinematic scroll and view transitions
- **Icons:** Lucide React for consistent, scalable iconography

## Core Features
- **High-Performance Image Loading:** Utilizes native `loading` (eager/lazy), `fetchPriority`, and `decoding` attributes to optimize image delivery and ensure a smooth user experience.
- **Scroll Animations:** Implements scroll-based motion and opacity transitions to create an immersive, editorial feel as the user explores the page.
- **Responsive Layout:** fully responsive fluid layout adapting from mobile devices to ultra-wide desktop monitors.
- **Optimized Assets:** High-priority hero visuals and lazily-loaded below-the-fold content to maximize performance metrics.
